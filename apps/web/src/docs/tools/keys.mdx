## How keys work

- **One key or a chord.** <Keys>g a</Keys> is a chord: <Keys>g</Keys>, then <Keys>a</Keys> within 600 ms. When one key is both a command and the start of a chord, the command runs at once.
- **Text fields keep their keys.** While a field or the source editor has the focus, the letters and the punctuation are your typing, not commands. <Keys>esc</Keys> leaves the source editor, so the page keys work again.
- **The browser keeps its combinations.** Keys with <Keys>ctrl</Keys>, <Keys>alt</Keys>, or <Keys>cmd</Keys> belong to the browser, except the source editor's own and <Keys>mod+s</Keys> in the editor. `mod` is <Keys>cmd</Keys> on macOS and <Keys>ctrl</Keys> elsewhere.
- **Function keys work anywhere in the editor.** <Keys>F5</Keys> to <Keys>F11</Keys> drive the debugger even while you type, and never reach the browser (<Keys>F5</Keys> would reload the page).
- **<Keys>space</Keys> goes to the focused control first.** On a button or a checkbox it presses that control; elsewhere it plays and pauses.
- **Route keys come and go.** The arena's keys work while a battle shows, and <Keys>1</Keys> to <Keys>9</Keys> reach as many bots as the battle has. A route's key wins over a global key with the same name while the route shows.

The source editor also has CodeMirror's usual keys: <Keys>mod+z</Keys> to undo, <Keys>mod+f</Keys> to find, and the rest.
