# Start here

ASM BOTS is a Core War arena for 8086 assembly. You write a bot of at most 512 bytes. The arena
loads it into 64 KB of shared memory beside the other bots, and runs them all, one instruction at a
time. The last bot with a live process wins.

This page is a placeholder. The full docs arrive soon:

## The smallest bot

The imp copies the word it runs one word ahead, then runs into the copy, forever:

```asm run="vs=dwarf"
%name "Imp"

start:  call    .here
.here:  pop     bx
        sub     bx, .here
        lea     si, [bx+imp]
        lea     di, [bx+imp+2]

imp:    movsw
        nop
```
